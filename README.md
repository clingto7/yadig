# yadig

音乐发现与资源挖掘 App。

## 核心功能

1. **周期音乐资讯推送** — 用户自定义信息源（网站 RSS、流媒体博主、乐评人、音乐人等），App 按日/周/月聚合推送音乐资讯
2. **音乐资源挖掘** — 用户输入关键词（流派/音乐人/厂牌/歌词/专辑/歌名/事件等），支持模糊搜索，在指定信息源和搜索引擎上查找，并可接入 LLM 进行智能整合
